Comment ça marche ?
Choisis le type de conditionnement de chaque produit avec ⚙ Conditionnement. L'application gère trois cas : boîte simple, boîtes dans un carton, ou unités dans un carton avec cartons sur palette. Seuls les champs utiles seront affichés.

Nouvelle référence

Après l’ajout, utilise « ⚙ Conditionnement » pour renseigner les quantités par boîte, carton ou palette.
